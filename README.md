# GamePad MIDI Sequencer - 操作マニュアル

このドキュメントは、WebベースのMIDIシーケンサーアプリケーション「GamePad MIDI Sequencer」の操作方法と仕様を説明します。

## 1. アプリケーション概要

GamePad MIDI Sequencerは、ゲームコントローラーで操作できるWeb MIDIシーケンサーです。ブラウザ上で動作し、8トラックのピアノロールを備えています。

## 2. システム要件

- **対応ブラウザ**: Chrome, Firefox, Edge（Web MIDI API対応）
- **ゲームコントローラー**: XInput/DirectInput対応ゲームパッド
- **ストレージ**: ローカルストレージ（設定・キー配置保存用）
- **対応ファイル形式**: 
  - SF2（SoundFont 2）
  - SFZ（サンプルベースのインストゥルメント）
  - JSON（プロジェクトファイル）
  - MIDI（エクスポートのみ）

## 3. 主要機能

### 3.1 ピアノロールエディター

ピアノロールは横軸が時間、縦軸がピッチ（MIDIノート番号）を表します。

| 要素 | 説明 |
|------|------|
| グリッド | 拍子分割に応じた編集グリッド |
| ノート | 配置された音符（ピンク色で表示） |
| ゴーストノート | 他トラックの音符（グレーで表示） |
| 選択範囲 | 青色でハイライトされる範囲 |
| カーソル | 現在の編集位置 |

### 3.2 トラック管理

最大8トラックの同時演奏が可能。各トラックには以下の設定があります：

- **ボリューム**: 0%〜100%
- **パン**: -1.0（左）〜1.0（右）
- **ミュート/ソロ**: 各トラックの演奏制御
- **楽器選択**: SF2/SFZからの選択


## 4. ファイル操作

### 4.1 プロジェクト管理

| 操作 | 方法 |
|------|------|
| 保存 | FILE → Save（JSON形式） |
| 読み込み | FILE → Load（JSON選択） |
| MIDIエクスポート | FILE → Export MIDI |

### 4.2 サウンドフォント読み込み

1. **SF2ファイル**: FILE → SF2 から .sf2 ファイルを選択
2. **SFZファイル**: FILE → SFZ から SFZファイルとサンプルを選択

## 5. ゲームコントローラー操作

### 5.1 ボタン配置（標準Xboxスタイル）

| ボタン | 機能 |
|--------|------|
| A（✕） | ノート配置/貼り付け |
| B（○） | 短押:コピー/長押:削除 |
| X（□） | 再生/停止 |
| Y（△） | 範囲選択モード |
| L1 | アンドゥ |
| R1 | リドゥ |
| L2 | グリッド変更モード |
| R2 | 移動速度変更 |
| START | 短押:次トラック/長押:トラックリスト |
| SELECT | ループ設定/トグル |
| 十字キー | カーソル移動 |
| 左スティック | カーソル移動 |

### 5.2 詳細操作

#### 通常操作
- **十字キー/左スティック**: カーソル移動
- **A**: ノート配置（カーソル位置に音符を追加/削除）
- **X**: カーソル位置から再生
- **B（短押）**: 選択範囲コピー
- **B（長押）**: 選択範囲削除

#### 修飾キー操作

| 組み合わせ | 機能 |
|-----------|------|
| A + 十字キー左右 | 音符の長さを変更 |
| A + 十字キー上下 | 音符の.velocityを変更 |
| Y + 十字キー | 範囲選択 |
| R2 + 十字キー | 快速移動（オクターブ/小節） |
| L2 + 十字キー左右 | グリッドサイズ変更（1/4 → 1/8 → 1/16...） |
| START + 十字キー上下 | ボリューム調整 |
| START + 十字キー左右 | パン調整 |
| START + A | Solo切替 |
| START + B | Mute切替 |

#### STARTボタンの特殊操作
- **短押（500ms未満）**: 次のトラックに切り替え
- **長押（500ms以上）**: トラックリストモーダルを開く

### 5.3 キー設定カスタマイズ

FILE → Controller Map からボタン配置を変更可能：
1. 変更したいボタンを選択
2. 新しいゲームパッドボタンを押す
3. 設定はローカルストレージに保存

## 7. トランスポート機能

### 7.1 テンポ・拍子

ADDメニューから追加可能：
- **BPM変更**: 任意の小節位置にテンポ変更を追加
- **拍子変更**: 任意の小節位置に拍子変更を追加

### 7.2 マーカー

ADD → Marker で現在位置にマーカーを追加：
- マーカーはA, B, C...の順で自動命名
- マーカーナビゲーターで前後のマーカーへ移動可能
- 同じ位置で再度追加すると削除

## 8. トラブルシューティング

### 8.1 ゲームパッドが認識されない
- USB接続を確認
- ブラウザでゲームパッドボタンを押して認識させる
- 別のUSBポートを試す

### 8.2 音が鳴らない
- ブラウザの音量が上がっているか確認
- ページをクリックしてオーディオコンテキストを初期化
- トラックのミュート状態を確認

### 8.3 SF2の読み込みエラー
- ファイルサイズを確認し、小さいファイルから試す
- ブラウザの開発者ツールでエラーメッセージを確認

## 9. 技術的仕様

### オーディオ処理
- サンプルレート: ブラウザ依存（通常44.1kHz/48kHz）
- ポリフォニー: 最大64ボイス
- エフェクト: リバーブ、コーラス、フィルター

### データ構造

プロジェクトのJSON構造：
```json
{
  "version": 1,
  "date": "ISO-8601タイムスタンプ",
  "songData": {
    "tracks": [
      {
        "id": 0-7,
        "name": "トラック名",
        "notes": [{"time": 拍, "pitch": MIDI番号, "duration": 長さ, "velocity": 音量}],
        "volume": 0.0-1.0,
        "pan": -1.0-1.0,
        "muted": false/true,
        "solo": false/true,
        "program": プログラム番号,
        "bank": バンク番号,
        "presetIndex": プリセットインデックス
      }
    ]
  },
  "transport": {
    "bpm": テンポ,
    "tempoMap": [{"beat": 拍, "bpm": テンポ}],
    "timeSigMap": [{"beat": 拍, "num": 分子, "den": 分母}],
    "markerMap": [{"beat": 拍, "label": "ラベル"}]
  }
}
```
