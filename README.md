# GamePad MIDI Sequencer - 操作マニュアル

このドキュメントは、WebベースのMIDIシーケンサーアプリケーション「GamePad MIDI Sequencer」の操作方法と仕様を説明します。

## 1. アプリケーション概要

GamePad MIDI Sequencerは、ゲームコントローラーで操作できるWeb MIDIシーケンサーです。ブラウザ上で動作します。
8トラックそれぞれでパターン（フレーズ）をピアノロールで作り、ソング画面でパターンを小節単位に並べて一曲を組み立てます。

## 2. システム要件

- **対応ブラウザ**: Chrome, Firefox, Edge（Web MIDI API対応）
- **ゲームコントローラー**: XInput/DirectInput対応ゲームパッド
- **ストレージ**: ローカルストレージ（設定・キー配置保存用）
- **対応ファイル形式**: 
  - SF2 / SF3（SoundFont）、DLS
  - SFZ（サンプルベースのインストゥルメント）
  - JSON（プロジェクトファイル）
  - MIDI（エクスポートのみ）

## 3. 主要機能

### 3.1 画面構成（SONG / PATTERN）

画面は2つあり、ヘッダーのタブまたは **SELECT長押し** で切り替えます。

| 画面 | 内容 |
|------|------|
| SONG | 縦にトラック、横に小節が並ぶ配置画面。パターンを「クリップ」として小節単位で置く |
| PATTERN | 1つのパターンを編集するピアノロール。パターンはトラックごとに A, B, C… と名前が付く |

- 同じパターンを複数の場所に置くと、どれか1つを編集すれば全部に反映されます（リンク）。
- パターンの長さは1〜64小節で、パターンごとに変えられます。
- SONG画面で再生すると曲全体、PATTERN画面で再生すると編集中のパターンだけがループ再生されます。

### 3.2 ピアノロールエディター（PATTERN画面）

ピアノロールは横軸が時間、縦軸がピッチ（MIDIノート番号）を表します。

| 要素 | 説明 |
|------|------|
| グリッド | 拍子分割に応じた編集グリッド |
| ノート | 配置された音符（ピンク色で表示） |
| ゴーストノート | 曲中の同じ位置で鳴る他トラックの音符（グレーで表示） |
| 暗い領域 | パターンの長さより後ろ（ここに置いた音符は鳴らない） |
| 選択範囲 | 青色でハイライトされる範囲 |
| カーソル | 現在の編集位置 |

### 3.3 トラック管理

最大8トラックの同時演奏が可能。各トラックには以下の設定があります：

- **ボリューム**: 0%〜100%
- **パン**: -1.0（左）〜1.0（右）
- **ミュート/ソロ**: 各トラックの演奏制御
- **楽器選択**: SF2/SFZからの選択


## 4. ファイル操作

### 4.1 プロジェクト管理

| 操作 | 方法 |
|------|------|
| 保存 | FILE → Save Project（JSON形式） |
| 読み込み | FILE → Load Project（JSON選択） |
| MIDIエクスポート | FILE → Export MIDI |

### 4.2 サウンドフォント読み込み

1. **SF2 / SF3 / DLS ファイル**: FILE → Load SoundFont からファイルを選択
2. **SFZファイル**: FILE → Load SFZ Folder から SFZファイルとサンプルの入ったフォルダを選択

音色はヘッダーのプリセット選択欄で、現在のトラックに設定します。

### 4.3 ダイアログ

BPM・拍子の入力や確認のダイアログは、ゲームパッドの **A = OK / B = キャンセル** でも操作できます。

## 5. ゲームコントローラー操作

### 5.1 ボタン配置（標準Xboxスタイル）

| ボタン | 機能 |
|--------|------|
| A（✕） | PATTERN: ノート配置/貼り付け　SONG: クリップ配置/パターンを開く |
| B（○） | 短押:コピー/長押:削除 |
| X（□） | 再生/停止 |
| Y（△） | 範囲選択モード |
| L1 | アンドゥ |
| R1 | リドゥ |
| L2 | 修飾キー（グリッド/ズーム/パターン長） |
| R2 | 移動速度変更 |
| START | 短押:次トラック/長押:トラックリスト |
| SELECT | 短押:ループ設定/トグル　長押:SONG⇔PATTERN切替 |
| 十字キー | カーソル移動 |
| 左スティック | カーソル移動 |

### 5.2 PATTERN画面（ピアノロール）

#### 通常操作
- **十字キー/左スティック**: カーソル移動
- **A**: ノート配置（カーソル位置に音符を追加/削除）
- **X**: カーソル位置から再生（パターン内をループ）
- **B（短押）**: 選択範囲コピー
- **B（長押）**: 選択範囲削除

#### 修飾キー操作

| 組み合わせ | 機能 |
|-----------|------|
| A + 十字キー左右 | 音符の長さを変更 |
| A + 十字キー上下 | 音符のベロシティを変更 |
| Y + 十字キー | 範囲選択 |
| R2 + 十字キー | 快速移動（オクターブ/小節） |
| L2 + 十字キー左右 | グリッドサイズ変更（1/4 → 1/8 → 1/16...） |
| L2 + 十字キー上下 | パターンの長さを1小節ずつ変更 |
| SELECT（選択中） | 選択した音符の範囲をループ区間に設定 |
| START + 十字キー上下 | ボリューム調整 |
| START + 十字キー左右 | パン調整 |
| START + A | Solo切替 |
| START + B | Mute切替 |

- STARTの短押しで次のトラックに切り替えると、そのトラックで最後に編集したパターンが開きます。

### 5.3 SONG画面（配置）

| 操作 | 機能 |
|------|------|
| 十字キー左右 / 上下 | カーソルを小節 / トラック単位で移動（R2併用で4小節ずつ） |
| A（空きマス） | そのトラックの現在のパターンを配置（パターンが無ければ新規作成） |
| A（クリップ上） | そのパターンをPATTERN画面で開く |
| A + 十字キー左右 | クリップのパターンの長さを1小節ずつ変更 |
| A + 十字キー上下 | クリップのパターンを切り替え（最後の次は新しい空のパターン） |
| B短押（クリップ上） | パターンを複製して別パターンにする（A → B など。バリエーション作り用） |
| B長押（クリップ上） | クリップを削除 |
| Y + 十字キー | 小節×トラックの範囲選択 |
| 選択中に十字キー左右 | 選択したクリップを移動 |
| 選択中にB短押 / B長押 | クリップをコピー / 削除（コピー後はAで貼り付け、B短押でクリップボード解除） |
| SELECT短押 | 選択範囲をループ区間に設定 / ループのON・OFF |
| L2 + 十字キー左右 | 横方向のズーム |
| X | カーソルの小節から再生（曲の最後で自動停止） |

マウスの場合は、クリックでカーソル移動、ダブルクリックでAボタンと同じ動作になります。

#### STARTボタンの特殊操作
- **短押（500ms未満）**: 次のトラックに切り替え
- **長押（500ms以上）**: トラックリストモーダルを開く

### 5.4 キー設定カスタマイズ

FILE → Controller Map からボタン配置を変更可能：
1. 変更したいボタンを選択
2. 新しいゲームパッドボタンを押す
3. 設定はローカルストレージに保存

## 7. トランスポート機能

### 7.1 テンポ・拍子

ADDメニューから追加可能：
- **BPM変更**: 任意の小節位置にテンポ変更を追加
- **拍子変更**: 任意の小節位置に拍子変更を追加

### 7.2 マーカー

ADD → Marker で現在位置にマーカーを追加：
- マーカーはA, B, C...の順で自動命名
- マーカーナビゲーターで前後のマーカーへ移動可能
- 同じ位置で再度追加すると削除

## 8. トラブルシューティング

### 8.1 ゲームパッドが認識されない
- USB接続を確認
- ブラウザでゲームパッドボタンを押して認識させる
- 別のUSBポートを試す

### 8.2 音が鳴らない
- ブラウザの音量が上がっているか確認
- ページをクリックしてオーディオコンテキストを初期化
- トラックのミュート状態を確認

### 8.3 SF2の読み込みエラー
- ファイルサイズを確認し、小さいファイルから試す
- ブラウザの開発者ツールでエラーメッセージを確認

## 9. 技術的仕様

### オーディオ処理
- SF2 / SF3 / DLS は [spessasynth](https://github.com/spessasus/spessasynth_lib)（AudioWorklet）で再生。エンベロープ・フィルター・モジュレーター・リバーブ/コーラスはSoundFontの仕様どおりに処理されます
- SFZは内蔵の簡易サンプラーで再生（`ampeg_*` のエンベロープに対応）
- 音源未読み込み時はサイン波
- ノートは少し先まで正確な時刻で予約して再生するため、描画の負荷で発音タイミングがずれません

### データ構造

プロジェクトのJSON構造（version 2。旧形式 version 1 のファイルは読み込めません）：
```json
{
  "version": 2,
  "date": "ISO-8601タイムスタンプ",
  "songData": {
    "version": 2,
    "nextId": 次に使うID,
    "tracks": [
      {
        "id": 0-7,
        "name": "トラック名",
        "volume": 0.0-1.0,
        "pan": -1.0-1.0,
        "muted": false/true,
        "solo": false/true,
        "program": プログラム番号,
        "bank": バンク番号（ドラムは128）,
        "presetIndex": プリセットインデックス
      }
    ],
    "patterns": [
      {
        "id": パターンID,
        "trackId": 所属トラック,
        "name": "A",
        "length": 長さ（拍）,
        "notes": [{"time": パターン先頭からの拍, "pitch": MIDI番号, "duration": 長さ, "velocity": 音量}]
      }
    ],
    "clips": [{"id": クリップID, "trackId": トラック, "patternId": パターンID, "start": 曲中の開始拍}]
  },
  "transport": {
    "bpm": テンポ,
    "tempoMap": [{"beat": 拍, "bpm": テンポ}],
    "timeSigMap": [{"beat": 拍, "num": 分子, "den": 分母}],
    "markerMap": [{"beat": 拍, "label": "ラベル"}]
  }
}
```
